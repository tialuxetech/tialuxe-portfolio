# Tialuxe Tech

The portfolio of Adetunji Tiamiyu, an independent developer working across WordPress, commerce, and modern front ends. It features selected projects, a short introduction to the work, and a contact form.

Built with Next.js, React, TypeScript, and CSS. The site is exported as static files; a Cloudflare Pages Function handles contact enquiries.

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Check and build

```bash
npm run lint
npm run build
```

The static site is written to `out/`.

For deployment, contact form setup, and content updates, see the [maintenance guide](docs/MAINTENANCE.md).
